# サーバー地図

サーバーの地図データ (.svg形式)

## `alldata.svg`のレイヤー構成

例: inkscape:label (Inkscape で付けた、レイヤーの名前を表す設定)

- 地形
- [MapArchive](https://github.com/TORO-Server/TOROMapArchive)
- 自治体
- 鉄道
- 鉄道駅
- 道路
- ガイド
